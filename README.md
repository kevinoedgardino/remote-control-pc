# CONTROL REMOTO PARA PC
Envía comandos de teclas básicas a la PC mediante un servidor web de Node.js y comunicación mediante WebSockets.

## Teclas habilitadas
- Apagado
- Subir volumen
- Mute/Unmute audio
- Bajar volumen
- Tab
- Espacio
- Enter
- Flecha arriba
- Flecha izquierda
- Flecha abajo
- Flecha derecha
